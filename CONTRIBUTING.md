# Contributing to CHTN

Thank you for your interest in contributing to CHTN!

## How to contribute

You can contribute by:

- Reporting bugs.
- Suggesting new features or improvements.
- Improving the documentation.
- Submitting pull requests.

## Before submitting code

- Follow the existing coding style.
- Test your changes before submitting.
- Keep pull requests focused on a single feature or fix.
- Write clear commit messages.

## Reporting bugs

When opening an issue, please include:

- Your operating system.
- Steps to reproduce the problem.
- Expected behavior.
- Actual behavior.
- Error messages or screenshots, if available.

## Feature requests

Please explain:

- What problem the feature solves.
- How you think it should work.
- Any alternatives you've considered.

## Questions

If you're unsure about anything, feel free to open an issue for discussion.

Thank you for helping improve CHTN!
